# Руководство пользователя

## Конвертер систем счисления

### Назначение
Программа переводит целые десятичные числа в системы счисления с основаниями от 2 до 16. В приложении доступны графический и консольный режимы, загрузка входных данных из TXT, сохранение результата, резервное копирование таблицы соответствия символов и журналирование.

### Состав проекта
- `main.py` — запуск графического или консольного режима;
- `gui.py` — окно программы и обработчики действий пользователя;
- `converter_logic.py` — алгоритм преобразования, проверка ввода, файловые операции, резервирование и настройка журнала;
- `data/encoding_mapping.json` — внутренняя таблица соответствия цифр и символов;
- `backup/` — резервные копии JSON-таблицы;
- `logs/app.log` — журнал работы;
- `TZ.docx` — техническое задание;
- `Service_Regulation.docx` — регламент технического обслуживания;
- `Test_case.docx` — тест-кейсы.

### Требования
- Python 3.10 или новее;
- Tkinter (обычно входит в установщик Python для Windows).

### Запуск
1. Откройте папку проекта в PyCharm.
2. Откройте `main.py`.
3. Нажмите **Run**.
4. Дождитесь появления окна конвертера.

Для консольного режима выполните в терминале из папки проекта команду `python main.py --console`.

### Преобразование числа
1. Введите целое десятичное число, например `255`.
2. Выберите основание от `2` до `16`.
3. Нажмите **«Преобразовать»**.
4. Для примера `255` при основании `16` программа покажет `FF`.

### Загрузка данных из файла
1. Создайте текстовый файл в кодировке UTF-8.
2. Укажите число и основание через пробел, например `255 16`.
3. Нажмите **«Загрузить из файла»** и выберите файл.
4. Проверьте параметры и результат преобразования.

Если основание не указано, используется основание `2`. Для простоты рекомендуется указывать оба значения в первой строке.

### Сохранение результата
1. Выполните преобразование.
2. Нажмите **«Сохранить результат»**.
3. Выберите папку и имя TXT-файла.
4. Откройте сохранённый файл и проверьте текст результата.

### Резервное копирование и восстановление
1. Нажмите **«Создать резервную копию»**. Копия таблицы будет сохранена в `backup/`.
2. Для восстановления нажмите **«Восстановить из копии…»**.
3. Выберите JSON-файл резервной копии.
4. Подтвердите замену текущей таблицы и дождитесь сообщения об успешном восстановлении.

### Журналирование
События приложения записываются в `logs/app.log`. При диагностике ошибки откройте этот файл и проверьте последние записи.

### Ограничения
Поддерживаются целые числа. Дробные значения и основания вне диапазона 2–16 не принимаются. Таблица JSON используется приложением для хранения соответствия символов и не изменяет системные кодировки операционной системы.
